# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Please don't open a public issue, pull request or discussion for a security problem.

Include what you found, how to reproduce it, and the version or commit affected.

You'll get an acknowledgement within 7 days. Once the issue is confirmed, I'll work on a fix, keep you updated in the advisory, and credit you when it's published unless you'd rather not be named.

## Supported versions

Only the latest release of each project receives security fixes.
